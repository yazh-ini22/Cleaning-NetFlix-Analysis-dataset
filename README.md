# Netflix Data Preprocessing

## 📌 Project Overview

This project focuses on cleaning and preprocessing the Netflix Movies and TV Shows dataset using Python and Pandas in Google Colab.

The purpose of the project is to transform the raw Netflix data into a clean and structured dataset that can be used for further analysis and Tableau dashboard development.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Google Colab
- Jupyter Notebook

## 🧹 Data Cleaning Process

The Netflix dataset was inspected and preprocessed using Python and Pandas.

The cleaning workflow includes:

- Loading the Netflix dataset
- Understanding the dataset structure
- Inspecting columns and data types
- Checking for missing values
- Checking for duplicate records
- Cleaning and preprocessing the data
- Handling data inconsistencies where required
- Converting and formatting date-related data
- Cleaning country and genre information
- Validating the cleaned dataset
- Preparing the final data for analysis and visualization

## 📊 Data Analysis Preparation

After the cleaning process, the dataset was structured and prepared for further analysis and visualization.

The cleaned data was used for:

- Movies and TV Shows analysis
- Genre analysis
- Country analysis
- Ratings analysis
- Release year analysis
- Content added over time
- Tableau dashboard development

## 📁 Project File

- `Tableau.ipynb` – Google Colab notebook containing the Python code and complete data cleaning and preprocessing process.
